工程符

How the benchmark is built 「五重结界」

Every question traces back to a structured field on a wiki page. Five commands in the touhouqa CLI take the wiki to a scored report.

Five steps from the wiki to a score, ze！

  1. touhouqa crawl

    Crawl

    Downloads THBWiki pages through the MediaWiki API, by namespace.

  2. touhouqa extract

    Extract

    Turns infobox fields into question and answer pairs, with an optional LLM pass.

  3. touhouqa split

    Split

    Splits by page so that no page appears in more than one split.

  4. touhouqa filter-core

    Filter core

    Keeps only unambiguous, high-precision questions for the Core track.

  5. touhouqa eval

    Evaluate

    Normalizes answers (NFKC, whitespace, punctuation, case) and scores exact matches.

奉纳符

Evaluate your model

The public question file contains only id and question. Gold answers stay with the maintainers.

Hand in your predictions.jsonl at the shrine.

Submit results

  1. Download the public questions for Core v1 or Full Test v1.
  2. Run your model and write one JSON object per line.
  3. Send predictions.jsonl to the maintainers. They score it against the hidden gold answers.
# predictions.jsonl
{"id": "q_000123", "answer": "博丽灵梦"}
{"id": "q_000124", "answer": "2002"}
touhouqa eval --gold <hidden> \
  --predictions predictions.jsonl \
  --report-out eval_report.json
